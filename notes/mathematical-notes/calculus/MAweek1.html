The first question is not how to substitute a number into a formula, but what the values of the formula do near that number. A function can have a limit at a point even when its value there is missing or different. We start with that distinction, make it precise, and then use it to study continuity.

  • R\mathbb{R}R denotes the set of all real numbers.

Lecture 1: approaching a point

1. Key idea

We use limits to describe the tendency of a function as the variable approaches a given point, but not the value at the point.

Definition of limit (Informal)

g(x)={2x,if x≠4,0,if x=4.g(x)= \begin{cases} 2x, & \text{if } x\ne4,\\ 0, & \text{if } x=4. \end{cases}g(x)={2x,0,​if x=4,if x=4.​

∣f(x)−L∣<εwhenever x∈I and 0<∣x−c∣<δ.|f(x)-L|<\varepsilon \quad\text{whenever }x\in I\text{ and }0<|x-c|<\delta.∣f(x)−L∣<εwhenever x∈I and 0<∣x−c∣<δ.

Simpler writing

We say lim⁡x→cf(x)=L\lim_{x\to c}f(x)=Llimx→c​f(x)=L if, for any ε>0\varepsilon>0ε>0, there exists δ>0\delta>0δ>0 such that

Personal interpretation

  • ε\varepsilonε: how close we require f(x)f(x)f(x) to be to LLL.

  • δ\deltaδ: how close xxx needs to be to ccc in order to satisfy that requirement.

  • ∣f(x)−L∣<ε|f(x)-L|<\varepsilon∣f(x)−L∣<ε: f(x)f(x)f(x) lies within an ε\varepsilonε-neighborhood of LLL.

  • 0<∣x−c∣<δ0<|x-c|<\delta0<∣x−c∣<δ: xxx lies within a δ\deltaδ-neighborhood of ccc, but x≠cx\ne cx=c.

The key idea is

Given any ε>0, we can find a δ>0\boxed{\text{Given any }\varepsilon>0,\text{ we can find a }\delta>0}Given any ε>0, we can find a δ>0​

such that

x is sufficiently close to c⟹f(x) is within ε of L.x\text{ is sufficiently close to }c \quad\Longrightarrow\quad f(x)\text{ is within }\varepsilon\text{ of }L.x is sufficiently close to c⟹f(x) is within ε of L.

In other words, ε\varepsilonε is the required accuracy for the output, while δ\deltaδ is how much accuracy we need for the input.

Thus, the ε\varepsilonε-δ\deltaδ definition gives a precise mathematical meaning to the intuitive statement: if xxx is sufficiently close to ccc, then f(x)f(x)f(x) is sufficiently close to LLL.

Useful remarks

The order of the quantifiers matters. The number δ\deltaδ may depend on ε\varepsilonε, on the function, and on the point ccc, but not on the particular xxx that will later be chosen. We need one radius that works for every point in the punctured interval. Making δ\deltaδ smaller never spoils a valid choice.

The condition 0<∣x−c∣0<|x-c|0<∣x−c∣ deliberately excludes ccc. Continuity will put the value at ccc back into the discussion.

We shall often use the following arguments:

  1. Let aaa be a real number. If, for every ε>0\varepsilon>0ε>0, we have a≤εa\leq\varepsilona≤ε, then a≤0a\leq0a≤0.

  2. Let aaa be a real number. If, for every ε>0\varepsilon>0ε>0, we have

−ε≤a≤ε,-\varepsilon\leq a\leq\varepsilon,−ε≤a≤ε,

then a=0a=0a=0.

Remark: Does the Converse Hold?

The Sum Rule requires that both limits on the right-hand side exist. In general, the converse is false: the existence of

lim⁡x→c(f(x)+g(x))\lim_{x\to c}(f(x)+g(x))x→clim​(f(x)+g(x))
