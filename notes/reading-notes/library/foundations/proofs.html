Studying Proofs & Mathematical Writing

Start here · Choose a text · Practice · Check your understanding · Continue · Full reading list

Proof-writing starts with knowing exactly what a statement allows you to assume and what it asks you to produce. Hammack separates logical language from direct proof, contradiction, counterexamples and induction, making it possible to repair one weakness at a time. Ernst takes a problem-led route in which constructing arguments is the main activity. Choose Hammack when you need explicit models of written reasoning; choose Ernst when you want sustained practice developing a claim before seeing a finished proof.

What to work on

  • Negate statements with nested quantifiers correctly.
  • Choose between direct proof, contrapositive and contradiction.
  • Write an induction argument with a stated base case and induction hypothesis.
  • Disprove a universal claim with a counterexample and explain why it qualifies.

A starting text

Book of Proof, third edition — Richard Hammack. Read sections 2.7 and 2.10 on quantifiers and negation; 4.3, 5.1 and 6.1 on proof methods; 5.3 on writing; then 9.1 and 10.1 on counterexamples and induction.

Choosing what to read

Rewrite a quantified statement in words, negate it, and test both versions on small examples. For each proof, name the domain and record where every hypothesis enters. Spend a second session revising an earlier argument for an unfamiliar reader. A correct answer with an unstated induction hypothesis or an undefined variable is a prompt for revision.

Try these before moving on

Try a proof or calculation before opening the hint. These solutions address the checks below, not the exercises in the linked textbooks.

  1. Negate: for every real x there is a real y with y > x. Then determine the truth of the original statement and its negation.

    A hint

    Reverse each quantifier, then negate the inequality. For the original statement, try choosing yyy in terms of xxx.

    Work through the solution

    The original statement is ∀x∈R  ∃y∈R  (y>x)\forall x\in\mathbb R\;\exists y\in\mathbb R\;(y>x)∀x∈R∃y∈R(y>x). It is true: given xxx, choose y=x+1y=x+1y=x+1.

    Its negation is ∃x∈R  ∀y∈R  (y≤x)\exists x\in\mathbb R\;\forall y\in\mathbb R\;(y\le x)∃x∈R∀y∈R(y≤x). This would assert a largest real number. It is false, since for any proposed xxx, the choice y=x+1y=x+1y=x+1 violates the required inequality. Notice that the choice of yyy is allowed to depend on xxx; swapping the quantifiers would ask a different question.

  2. Prove that an integer n is even if and only if n squared is even, giving each implication separately.

    A hint

    One direction follows by writing n=2kn=2kn=2k. For the other, prove the contrapositive using the form of an odd integer.

    Work through the solution

    If n=2kn=2kn=2k for some integer kkk, then n2=4k2=2(2k2)n^2=4k^2=2(2k^2)n2=4k2=2(2k2) is even.

    For the converse, suppose that nnn is odd. Write n=2k+1n=2k+1n=2k+1. Then

    n2=4k2+4k+1=2(2k2+2k)+1,n^2=4k^2+4k+1=2(2k^2+2k)+1,n2=4k2+4k+1=2(2k2+2k)+1,

    so n2n^2n2 is odd. The contrapositive gives: if n2n^2n2 is even, then nnn is even. Both directions are needed for the equivalence.

  3. Prove by induction that 1 + 3 + ... + (2n - 1) = n squared for every integer n >= 1.

    A hint

    After assuming the formula for nnn, identify the next odd summand before doing any algebra.

    Work through the solution

    For n=1n=1n=1, the sum is 1=121=1^21=12. Suppose the statement holds for an integer n≥1n\ge1n≥1. The next odd summand is 2(n+1)−1=2n+12(n+1)-1=2n+12(n+1)−1=2n+1, so

    ∑k=1n+1(2k−1)=n2+(2n+1)=(n+1)2.\sum_{k=1}^{n+1}(2k-1)=n^2+(2n+1)=(n+1)^2.k=1∑n+1​(2k−1)=n2+(2n+1)=(n+1)2.

    This proves the induction step. Together with the base case, it establishes the identity for every integer n≥1n\ge1n≥1. The induction hypothesis was used to replace only the first nnn summands by n2n^2n2, not to assume the desired formula at n+1n+1n+1.

Already comfortable with this? Skip the introductory proof-method readings if you can complete all three checks, state each domain and hypothesis, and revise a proof so every inference is justified. Review quantifiers alone if negation is the remaining gap.
