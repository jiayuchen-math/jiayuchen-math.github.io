Studying Set Theory

Start here · Choose a text · Practice · Check your understanding · Continue · Full reading list

Counting elements and comparing order types answer different questions. Two sets may be equinumerous while their chosen well-orders behave differently under addition. Button's text makes that transition within an introductory axiomatic route; Halmos offers a shorter account of sets, order and cardinality. Either can support the early language, but the ordinal calculations deserve their own written examples rather than being absorbed as unfamiliar notation.

What to work on

  • Prove countability by constructing an enumeration or injection.
  • Apply Cantor's diagonal argument to a power set.
  • Distinguish ordinal addition from cardinal addition.
  • Explain the role of replacement, transfinite recursion and choice in basic constructions.

A starting text

Set Theory: An Open Introduction — Tim Button, based on the Open Logic Project. Use sections 5.2 and 5.6-5.9 for cardinality; 10.3-10.7 and 10.9-10.10 for well-orders, ordinals and replacement; 11.2 for transfinite recursion; 13.2-13.3 for ordinal addition; 15.1-15.2 for cardinal arithmetic; and 16.4 for choice and well-ordering.

Choosing what to read

Construct actual injections and bijections before using cardinal equations. Draw the order types of omega, omega plus one and one plus omega, then explain the difference without appealing only to symbols. When a construction iterates through all earlier stages, identify the recursion theorem and the relevant existence assumptions. Keep an axiom ledger for replacement and choice: record what each permits and which argument would be incomplete without it.

Try these before moving on

Try a proof or calculation before opening the hint. These solutions address the checks below, not the exercises in the linked textbooks.

  1. Construct an explicit injection from the integers into the natural numbers, then prove no map A -> P(A) can be surjective.

    A hint

    Send nonnegative and negative integers to disjoint parity classes. For the power set, form a subset whose membership disagrees with its proposed preimage.

    Work through the solution

    Using N={0,1,2,…}\mathbb N=\{0,1,2,\ldots\}N={0,1,2,…}, define j(n)=2nj(n)=2nj(n)=2n for n≥0n\ge0n≥0 and j(n)=−2n−1j(n)=-2n-1j(n)=−2n−1 for n<0n<0n<0. The first branch has even values and the second has odd values, so equality of outputs forces the inputs into the same branch. Each branch is injective, hence so is jjj.

    For any set AAA and map f:A→P(A)f:A\to\mathcal P(A)f:A→P(A), the subset D={a∈A:a∉f(a)}D=\{a\in A:a\notin f(a)\}D={a∈A:a∈/f(a)} belongs to P(A)\mathcal P(A)P(A). If fff were onto, some b∈Ab\in Ab∈A would satisfy f(b)=Df(b)=Df(b)=D. Then b∈Db\in Db∈D if and only if b∉f(b)=Db\notin f(b)=Db∈/f(b)=D, a contradiction. Thus no such map is surjective; the argument also covers A=∅A=\varnothingA=∅.
