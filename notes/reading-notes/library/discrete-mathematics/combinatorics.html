Studying Combinatorics & Graph Theory

Start here · Choose a text · Practice · Check your understanding · Continue · Full reading list

Counting is often a choice of representation: the same objects can be described by subsets, recurrences, graphs or generating functions. Keller and Trotter provide a broad route across these descriptions. Stanley connects graph walks, trees and tableaux with algebra. Choose the broad route while learning basic counting arguments; choose the algebraic continuation when matrices and linear maps can help explain a combinatorial formula.

What to work on

  • Prove counting identities by a bijection or double count.
  • Use inclusion-exclusion with precisely defined events.
  • Encode counting sequences in ordinary generating functions.
  • Use degree counts, paths, cycles and trees in graph arguments.

A starting text

Applied Combinatorics, 2016 edition — Mitchel T. Keller and William T. Trotter. Read chapter 2, Strings, Sets, and Binomial Coefficients; chapter 5, Graph Theory; chapter 7, Inclusion-Exclusion; and chapter 8, Generating Functions. Chapter 9 continues to recurrence equations.

Choosing what to read

Explain what each side of a counting identity counts before simplifying algebra. For a recurrence, state the initial values and justify the decomposition producing it. Translate the recurrence into a generating function and recover several coefficients as a check. In graph theory, draw the small and disconnected cases before committing to a universal claim. Keep formal power series distinct from analytic convergence arguments; the calculation may require only coefficient identities, or it may need additional estimates.

Try these before moving on

Try a proof or calculation before opening the hint. These solutions address the checks below, not the exercises in the linked textbooks.

  1. Find an ordinary generating function for the number of binary strings of length n with no adjacent ones, starting with the empty string; derive its recurrence and initial values.

    A hint

    For n at least 2, partition strings by whether they end in 0 or in 01. Work with a formal power series so no analytic convergence assumption is needed.

    Work through the solution

    Let ana_nan​ count such strings. The empty string gives a0=1a_0=1a0​=1, and the strings 0,10,10,1 give a1=2a_1=2a1​=2. For n≥2n\ge2n≥2, a valid string ending in 000 is obtained uniquely by appending 000 to a valid string of length n−1n-1n−1. A valid string ending in 111 must end in 010101, and deleting that suffix gives a valid string of length n−2n-2n−2. These disjoint classes exhaust the strings, so an=an−1+an−2a_n=a_{n-1}+a_{n-2}an​=an−1​+an−2​.

    A(x)=1+x1−x−x2.A(x)=\frac{1+x}{1-x-x^2}.A(x)=1−x−x21+x​.

    The denominator has constant coefficient 111, hence is invertible as a formal power series. The first coefficients are 1,2,3,5,81,2,3,5,81,2,3,5,8, agreeing with the recurrence.

    If this was the sticking point:

    • Proofs & Mathematical Writing — Review exhaustive disjoint cases and bijections used in counting.
    • Abstract Algebra & Galois Theory — Review coefficient arithmetic in formal power series if manipulating generating functions is unfamiliar.

Already comfortable with this? Skip counting basics if you can give the double count and a valid inclusion-exclusion argument. Skip the generating-function and graph review only if you can derive the recurrence and tree proof without relying on memorized formulas.
