狄利克雷特征的高斯和

Number Theory · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: character Gauss sum

Translation evidence: Literature usage

Meaning in context

For a Dirichlet character χ\chiχ modulo NNN, τ(χ)=∑a mod Nχ(a)e2πia/N\tau(\chi)=\sum_{a\bmod N}\chi(a)e^{2\pi i a/N}τ(χ)=∑amodN​χ(a)e2πia/N.

模 NNN 的狄利克雷特征 χ\chiχ 的高斯和为 τ(χ)=∑a mod Nχ(a)e2πia/N\tau(\chi)=\sum_{a\bmod N}\chi(a)e^{2\pi i a/N}τ(χ)=∑amodN​χ(a)e2πia/N。

Example

For the nontrivial character modulo 333, τ(χ)=e2πi/3−e4πi/3=i3\tau(\chi)=e^{2\pi i/3}-e^{4\pi i/3}=i\sqrt3τ(χ)=e2πi/3−e4πi/3=i3​.

Usage and distinctions

The magnitude formula ∣τ(χ)∣=N|\tau(\chi)|=\sqrt N∣τ(χ)∣=N​ requires primitivity; the finite sum is defined more generally.
