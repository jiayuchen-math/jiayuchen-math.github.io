Other names / variants: injection

Translation evidence: Literature usage

Meaning in context

A function f:A→Bf:A\to Bf:A→B for which f(x)=f(y)f(x)=f(y)f(x)=f(y) implies x=yx=yx=y for all x,y∈Ax,y\in Ax,y∈A.

对所有定义域元素 x、y，f(x)=f(y) 都推出 x=y 的映射。

Example

n↦5nn\mapsto5nn↦5n is an injection Z→Z\mathbb Z\to\mathbb ZZ→Z.

Usage and distinctions

Injectivity prohibits collisions; it does not require covering the codomain.
