广义函数

Analysis, Measure & PDE · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A distribution on an open set Omega in R^n is a continuous linear functional on C_c^infinity(Omega); locally, its action is bounded by finitely many derivative suprema of tests with support in a fixed compact set.

分析中的广义函数，是开集上紧支撑光滑测试函数空间的连续线性泛函；固定紧支集后，其作用可由有限多个导数的上确界控制。

Example

δ2(φ)=φ(2)\delta_2(\varphi)=\varphi(2)δ2​(φ)=φ(2) is a distribution, with ∣δ2(φ)∣≤sup⁡∣φ∣|\delta_2(\varphi)|\le\sup|\varphi|∣δ2​(φ)∣≤sup∣φ∣.

Usage and distinctions

This sense of distribution is a generalized function, not a probability law; point evaluation need not come from an integrable function.
