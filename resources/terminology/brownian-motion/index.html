布朗运动

Probability · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: Wiener process · 维纳过程

Translation evidence: Literature usage

Meaning in context

A process BtB_tBt​ starting at zero, with almost surely continuous paths and independent increments on disjoint intervals, such that Bt−Bs∼N(0,t−s)B_t-B_s\sim N(0,t-s)Bt​−Bs​∼N(0,t−s) for 0≤s<t0\le s<t0≤s<t.

从0出发、轨道几乎必然连续、不同时间区间增量独立，且s至t的增量服从均值0方差t−s正态分布的过程。

Example

For standard Brownian motion, E[BsBt]=min⁡(s,t)E[B_sB_t]=\min(s,t)E[Bs​Bt​]=min(s,t).

Usage and distinctions

Normal marginals alone are insufficient; this definition explicitly includes continuity and uses elapsed time as variance.
