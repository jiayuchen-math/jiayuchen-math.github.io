随机变量

Probability · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: r.v.

Translation evidence: Literature usage

Meaning in context

A real-valued measurable map X:(Ω,F)→(R,B(R))X:(\Omega,\mathcal F)\to(\mathbb R,\mathcal B(\mathbb R))X:(Ω,F)→(R,B(R)) on a probability space.

概率空间上取实数值的可测函数；每个Borel集合的原像必须是事件。

Example

If AAA is an event, X=1AX=1_AX=1A​ is a random variable.

Usage and distinctions

A random variable is a function; its observed value and its distribution are different objects.
