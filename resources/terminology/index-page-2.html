binomial random graph 随机图

Combinatorics · Undergraduate

For n ≥ 0 and 0 ≤ p ≤ 1, G(n,p) is the random simple graph on a fixed labeled n-vertex set in which each possible edge is included independently with probability p.

Encyclopedia

bipartite graph 二部图

Combinatorics · Undergraduate · Short definition only

A simple graph is bipartite if its vertex set admits a partition into two disjoint parts such that every edge has one endpoint in each part.

bound variable occurrence 约束出现

Foundations & Logic · Undergraduate · Short definition only

An occurrence of a variable within the scope of a quantifier for that variable, bound by the nearest such quantifier.

bounded linear operator 有界线性算子

Analysis, Measure & PDE · Graduate · Short definition only

A linear map T between normed spaces is bounded when some finite C satisfies norm(Tx)<=C norm(x) for every domain vector x.

cardinality of a set 基数

Foundations & Logic · Undergraduate

In ZFC, the least ordinal bijective with a set; equality of cardinalities is equivalently existence of a bijection.

Encyclopedia

Cartesian product 笛卡尔积

Foundations & Logic · Undergraduate · Short definition only

For sets A and B, the set of ordered pairs with first coordinate in A and second in B.

categorical colimit 余极限

Category Theory · Graduate · Short definition only

For a small diagram, a cocone from which every compatible cocone factors by a unique map of vertices respecting all legs.

categorical coproduct 余积

Category Theory · Undergraduate · Short definition only

An object with maps from a specified family such that each family of maps into any Y extends uniquely to a map from that object to Y.

categorical equalizer 等化子

Category Theory · Graduate · Short definition only

For parallel f,g:A→B, a map e:E→A with fe=ge universal among maps with that equality.

categorical limit 极限

Category Theory · Graduate

For a small diagram D:J→C, a cone through which every other cone factors by a unique vertex map respecting all legs.

Encyclopedia

categorical product 积

Category Theory · Undergraduate

Objects P with projections to a specified family such that every matching family of maps from any X arises uniquely from a map X→P.

Encyclopedia

categorical pullback 拉回

Category Theory · Graduate

For A→C←B, an object P with maps to A and B making the square commute and universal among such commuting pairs.

Encyclopedia

category 范畴

Category Theory · Undergraduate

Objects and directed morphisms with specified sources, targets, associative composition and a two-sided identity at each object.

Encyclopedia

Cauchy integral formula 柯西积分公式

Analysis, Measure & PDE · Undergraduate · Short definition only

If f is holomorphic near the closed disk of radius r centered at a, then for every z in that disk's interior, f(z)=(2 pi i)^(-1) integral_{|w-a|=r} f(w)/(w-z) dw with counterclockwise orientation.

Cauchy sequence 基本列

Analysis, Measure & PDE · Undergraduate · Short definition only

A sequence x_n in a metric space is Cauchy if for every epsilon > 0 some N makes d(x_m,x_n) = N.

Cauchy–Riemann equations 柯西-黎曼方程

Analysis, Measure & PDE · Undergraduate · Short definition only

For f=u+iv on a plane domain, the Cauchy–Riemann equations are u_x=v_y and u_y=-v_x. Under C^1 regularity they characterize holomorphicity.

cellular homology 胞腔同调

Geometry & Topology · Graduate

For a CW complex, the homology of the chain complex with C_n=H_n(X^n,X^{n-1};Z), whose boundary is formed from the relative connecting map followed by projection to the next skeletal pair.

Encyclopedia

central limit theorem 中心极限定理

Probability · Undergraduate

The classical iid central limit theorem states that for real iid $X_j$ with mean $\mu$ and variance $0<\sigma^2<\infty$, $(\sum_{j=1}^n X_j-n\mu)/(\sigma\sqrt n)$ converges in distribution to $N(0,1)$.

Encyclopedia

chain complex of modules 模的链复形

Algebra & Algebraic Geometry · Graduate

Modules $C_n$ and maps $d_n:C_n\to C_{n-1}$ with $d_{n-1}d_n=0$ for every integer $n$.

Encyclopedia

characteristic function of a probability distribution 特征函数

Probability · Undergraduate

For a real random variable $X$, the function $\varphi_X(t)=E[e^{itX}]$ for $t\in\mathbb R$, using this sign convention.

Encyclopedia

characteristic polynomial of a linear map 线性映射的特征多项式

Algebra & Algebraic Geometry · Undergraduate · Short definition only

For an endomorphism of an $n$-dimensional $F$-space, the basis-independent monic polynomial $\det(xI-A)$.

Chinese remainder theorem for integers 整数中国剩余定理

Number Theory · Undergraduate

For pairwise coprime positive integers $m_1,\ldots,m_r$, any prescribed residues have a simultaneous integer solution unique modulo $\prod_i m_i$.

Encyclopedia

chromatic number 色数

Combinatorics · Undergraduate

The chromatic number χ(G) of a finite simple graph is the least nonnegative integer k admitting a vertex coloring with k colors in which adjacent vertices receive different colors.

Encyclopedia

class number of a number field 数域的类数

Number Theory · Graduate · Short definition only

The finite cardinality $h_K=|\operatorname{Cl}(K)|$ of the ideal class group of a number field $K$.
