martingale 鞅

Probability · Graduate

An adapted discrete-time process $M_n$ with $E|M_n|<\infty$ and $E[M_{n+1}\mid\mathcal F_n]=M_n$ almost surely for each $n$, relative to a specified filtration.

matching in a graph 匹配

Combinatorics · Undergraduate · Short definition only

A matching in a finite simple graph is a subset of edges such that no two chosen edges share an endpoint.

material implication 蕴涵

Foundations & Logic · Undergraduate · Short definition only

The classical connective $P\to Q$, false exactly when $P$ is true and $Q$ is false.

mathematical induction 数学归纳法

Foundations & Logic · Undergraduate

For $P$ on $\mathbb N$, the principle that $P(0)$ and every implication $P(n)\to P(n+1)$ together yield $\forall n\,P(n)$.

Encyclopedia

maximal ideal 极大理想

Algebra & Algebraic Geometry · Undergraduate · Short definition only

A proper ideal not strictly contained in any other proper ideal of the ring.

maximal matching 极大匹配

Combinatorics · Undergraduate · Short definition only

A maximal matching is a matching not properly contained in another matching of the same graph.

maximum matching 最大匹配

Combinatorics · Undergraduate · Short definition only

A maximum matching of a finite graph is a matching with at least as many edges as every other matching of that graph.

mean value theorem for real functions 微分中值定理

Analysis, Measure & PDE · Undergraduate · Short definition only

If a real function f is continuous on [a,b], differentiable on (a,b), and a<b, some c in (a,b) satisfies f'(c)=(f(b)-f(a))/(b-a).

measurable real function 可测函数

Analysis, Measure & PDE · Undergraduate · Short definition only

A real function f on a measurable space (X,A) is measurable when the inverse image of every Borel subset of R belongs to A; equivalently each set {x:f(x)>t} is measurable.

measure space 测度空间

Analysis, Measure & PDE · Undergraduate · Short definition only

A measure space (X,A,mu) consists of a set X, a sigma-algebra A of its subsets, and a nonnegative extended-real function mu on A with mu(empty)=0 and countable additivity on disjoint measurable sets.

measure-preserving transformation 保测变换

Dynamical Systems · Graduate · Short definition only

On a measure space $(X,\mathcal B,\mu)$, a measurable self-map $T$ that satisfies $\mu(T^{-1}A)=\mu(A)$ for all $A\in\mathcal B$.

meromorphic function 亚纯函数

Analysis, Measure & PDE · Undergraduate · Short definition only

A meromorphic function on a complex domain is holomorphic except at a discrete set of poles, with the identically infinite function excluded here.

metrizable space 可度量化

Geometry & Topology · Undergraduate · Short definition only

A topological space whose topology is induced by some metric.

minimal dynamical system 极小系统

Dynamical Systems · Undergraduate · Short definition only

A continuous self-map of a nonempty compact space is minimal when every forward orbit is dense in the whole space.

minimal polynomial of an algebraic element 代数元的极小多项式

Algebra & Algebraic Geometry · Undergraduate · Short definition only

The unique monic polynomial of smallest positive degree in $K[x]$ annihilating an algebraic element $\alpha$.

Möbius function on positive integers 默比乌斯函数

Number Theory · Undergraduate · Short definition only

$\mu(1)=1$; $\mu(n)=(-1)^r$ if $n$ is a product of $r$ distinct primes, and $\mu(n)=0$ if a prime square divides $n$.

Möbius inversion for divisor sums 默比乌斯反演

Number Theory · Undergraduate · Short definition only

For functions on positive integers, $F(n)=\sum_{d\mid n}f(d)$ implies $f(n)=\sum_{d\mid n}\mu(n/d)F(d)$.

modular function 模函数

Number Theory · Graduate · Short definition only

For a congruence subgroup $\Gamma$, a meromorphic function on the upper half-plane invariant under $\Gamma$ and meromorphic at all cusps, equivalently a meromorphic weight-zero modular form.

module homomorphism 模同态

Algebra & Algebraic Geometry · Graduate · Short definition only

An additive map $f:M\to N$ between left $R$-modules satisfying $f(rm)=rf(m)$.

monoid 幺半群

Algebra & Algebraic Geometry · Undergraduate · Short definition only

A set with an associative binary operation and a two-sided identity element.

monotone convergence theorem 非负单调收敛定理

Analysis, Measure & PDE · Undergraduate · Short definition only

If measurable functions 0<=f_n increase pointwise to f on a measure space, then their integrals increase to the integral of f, allowing the value infinity.

morphism in a category 态射

Category Theory · Undergraduate · Short definition only

An arrow with a specified source and target in a category, composable with other arrows when their endpoints match.

Morse function Morse函数

Geometry & Topology · Graduate

A smooth real-valued function on a smooth manifold whose Hessian at each critical point is a nonsingular symmetric bilinear form; functions with no critical points are included.
