de Rham 上同调

Geometry & Topology · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

For a smooth manifold, the real vector spaces obtained in each degree by dividing the closed smooth differential forms by the exact ones, using the exterior derivative; degree zero has no incoming differential.

对光滑流形，逐次数将闭的光滑微分形式空间除以恰当形式空间所得的实向量空间；微分为外微分，零次没有流入的微分。

Example

On S1S^1S1, η=x dy−y dx\eta=x\,dy-y\,dxη=xdy−ydx has integral 2π2\pi2π. Hence it is closed but cannot equal dfdfdf for a global function, giving a nonzero class in HdR1(S1)H^1_{\mathrm{dR}}(S^1)HdR1​(S1).

Usage and distinctions

Local primitives do not supply a global primitive. Integral singular cohomology can have torsion, whereas these groups use real coefficients.
