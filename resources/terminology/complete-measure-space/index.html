完备测度空间

Analysis, Measure & PDE · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A measure space is complete if every subset of each measurable null set is measurable.

测度空间若每个可测零测集的任意子集也可测，则称为完备测度空间。

Example

Lebesgue measure on its full Lebesgue sigma-algebra is complete; restriction to the Borel sigma-algebra is not.

Usage and distinctions

Measure completeness concerns null subsets; metric completeness concerns Cauchy limits and is a different property.
