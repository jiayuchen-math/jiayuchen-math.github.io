有界线性算子

Analysis, Measure & PDE · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A linear map T between normed spaces is bounded when some finite C satisfies norm(Tx)<=C norm(x) for every domain vector x.

赋范空间之间的线性映射若有一个有限常数 C，使每个向量的像范数不超过 C 倍原范数，则为有界线性算子。

Example

For T(x,y)=(2x,−y)T(x,y)=(2x,-y)T(x,y)=(2x,−y) in Euclidean norm, ∥T(x,y)∥≤2∥(x,y)∥\|T(x,y)\|\le2\|(x,y)\|∥T(x,y)∥≤2∥(x,y)∥.

Usage and distinctions

A bounded linear operator maps bounded sets to bounded sets, but its image on the entire nonzero vector space is usually unbounded.
