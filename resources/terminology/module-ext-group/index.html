Meaning in context

For left RRR-modules M,NM,NM,N, Ext⁡Rn(M,N)\operatorname{Ext}^n_R(M,N)ExtRn​(M,N) is degree-nnn cohomology of Hom⁡R(P∙,N)\operatorname{Hom}_R(P_\bullet,N)HomR​(P∙​,N) for a projective resolution P∙→MP_\bullet\to MP∙​→M.

将第一变量的投射解消施以到第二变量的 Hom 后取第 nnn 次上同调所得的群。

Example

Ext⁡Z1(Z/2,Z)≅Z/2\operatorname{Ext}^1_{\mathbb Z}(\mathbb Z/2,\mathbb Z)\cong\mathbb Z/2ExtZ1​(Z/2,Z)≅Z/2.

Usage and distinctions

Ext⁡0\operatorname{Ext}^0Ext0 is Hom, while Ext⁡1\operatorname{Ext}^1Ext1 classifies extensions with fixed outer terms.
