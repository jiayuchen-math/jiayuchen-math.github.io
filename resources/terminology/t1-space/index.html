T1 分离公理

Geometry & Topology · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: T1 separation

Translation evidence: Literature usage

Meaning in context

A topological space in which every singleton is closed.

每个单点集均为闭集的拓扑空间。

Example

An infinite set with the cofinite topology is T1.

Usage and distinctions

T1 does not imply Hausdorff separation: two nonempty opens in an infinite cofinite space always intersect.
