局部小范畴

Category Theory · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A category whose collection of morphisms between each fixed pair of objects is a set.

任意固定的一对对象之间的态射构成集合的范畴。

Example

Set\mathbf{Set}Set is locally small although the class of all sets is not a set.

Usage and distinctions

The Chinese source explicitly uses 局部 U-小范畴; this entry suppresses the fixed universe, as its convention allows.
