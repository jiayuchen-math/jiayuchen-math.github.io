Analysis, Measure & PDE · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

For an integer m>=0 and a real C^{m+1} function on an interval containing a and x, Taylor's formula writes f(x)=sum_{k=0}^m f^{(k)}(a)(x-a)^k/k! + (1/m!) integral_a^x (x-t)^m f^{(m+1)}(t) dt.

实函数在包含 a 和 x 的区间上具有连续的 m+1 阶导数时，可表示为 a 处直到 m 阶的 Taylor 多项式加上由 m+1 阶导数积分构成的余项。

Usage and distinctions

This is a finite expansion with a controlled remainder; smoothness alone does not guarantee equality with an infinite Taylor series.
