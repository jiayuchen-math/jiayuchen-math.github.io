树

Combinatorics · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A tree is a nonempty connected simple graph containing no cycle; this record restricts to finite trees.

本记录中，树是非空、连通且不含圈的有限简单图。

Example

The graph with edges ab,ac,adab,ac,adab,ac,ad is a tree on four vertices.

Usage and distinctions

A forest need not be connected. A one-vertex graph is a tree even though it has no degree-one leaf.
