完全性定理

Foundations & Logic · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: Gödel completeness theorem

Translation evidence: Literature usage

Meaning in context

For a sound complete classical first-order calculus, every semantic consequence of a sentence set has a finite derivation from it.

对于可靠且完全的经典一阶演绎系统，语句集的每个语义后承都有从该集合出发的有限推演。

Example

If Γ⊨Q(c)\Gamma\models Q(c)Γ⊨Q(c), completeness supplies Γ⊢Q(c)\Gamma\vdash Q(c)Γ⊢Q(c).

Usage and distinctions

Completeness of the logic does not assert that an individual theory decides every sentence.
