函子

Category Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: covariant functor · 共变函子

Translation evidence: Literature usage

Meaning in context

An assignment of objects and arrows between categories that respects source, target, identities and composition.

范畴之间同时指定对象和态射的对应，并保持来源、目标、恒等态射和合成的结构。

Example

A↦A×AA\mapsto A\times AA↦A×A, f↦f×ff\mapsto f\times ff↦f×f, is a functor on sets.

Usage and distinctions

An object assignment alone is insufficient; preservation of identities must also be checked.
