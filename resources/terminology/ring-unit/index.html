环的可逆元

Algebra & Algebraic Geometry · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: invertible element of a ring

Translation evidence: Literature usage

Meaning in context

An element uuu in a unital ring admitting vvv with uv=vu=1uv=vu=1uv=vu=1.

在含幺环中具有双侧乘法逆元的元素。

Example

The units of Z\mathbb ZZ are 1,−11,-11,−1.

Usage and distinctions

In a noncommutative ring, a one-sided inverse is not sufficient.
