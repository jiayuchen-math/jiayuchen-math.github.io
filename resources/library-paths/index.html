Learning Paths

Choose a destination, then follow a connected route from foundations through core study to more advanced branches.

Choose a direction · Review a single prerequisite · Library cards

Reading a mathematics text — choosing a book, working through proofs, and using hints without losing the problem.

Toward algebraic geometry

Understand schemes, sheaves and the tools needed to choose a first research-level geometry text.

Foundation: proof and algebra → Bridge: local algebra and gluing → Core: varieties and schemes → Further branches

Toward representation theory

Move from linear maps and group actions to representations and Lie-theoretic reading.

Foundation: linear structures → Bridge: abstract algebra → Core: representations and Lie theory → Further tools

Toward functional analysis and PDE

Reach functional-analytic and weak-solution methods from a first rigorous analysis course.

Foundation: rigorous analysis → Bridge: integration and function spaces → Core: differential equations → Further branches

Toward complex and harmonic analysis

Build a foundation for Fourier methods, complex variables and advanced analytic estimates.

Foundation: real variables → Bridge: two parallel languages → Core: operators and Fourier analysis → Further reading

Toward differential and symplectic geometry

Progress from multivariable calculus to manifolds, curvature and a chosen geometric branch.

Foundation: local calculations and topology → Core: smooth geometry → Bridge: global invariants → Further branch: symplectic geometry

Toward algebraic topology and homotopy

Connect topological spaces with algebraic invariants and higher homotopical methods.

Foundation: spaces and algebra → Core: fundamental groups and homology → Bridge: complexes and categorical language → Further reading: homotopy theory

Toward advanced number theory

Start with elementary arithmetic, then choose algebraic, analytic or modular directions.

Foundation: arithmetic and proof → Algebraic branch → Analytic branch → Connecting branch: modular forms

Toward logic, set theory and model theory

Move from mathematical language to formal systems and a chosen foundations specialization.

Foundation: mathematical language → Core: logic and sets → Bridge: algebraic examples → Further branches

Toward measure-theoretic probability

Connect elementary random variables with rigorous probability and stochastic-process reading.

Foundation: calculation and random variables → Bridge: rigorous integration → Core: rigorous probability → Further branches

Toward dynamical systems and ergodic theory

Progress from iteration and flows to invariant measures and ergodic methods.

Foundation: analysis and spaces → Core: maps and flows → Bridge to the measurable branch → Further reading: ergodic theory

Toward advanced combinatorics

Build from counting and graph arguments toward algebraic, extremal or probabilistic methods.

Foundation: discrete proof → Choose supporting tools → Core and further branches

Toward categories and higher structures

Move from concrete universal properties toward homotopical and higher-categorical reading.

Foundation: algebraic examples → Core: ordinary categories → Homotopical bridge → Further reading: higher structures
