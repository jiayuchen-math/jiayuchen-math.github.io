Number Theory · Graduate · Mathematics Resources editorial compilation (AI-assisted)

The ordinary Hilbert class field is the maximal abelian extension unramified at finite places and split at real places, with Galois group canonically identified with the ideal class group.

Chinese translation, usage & terminology

Prerequisite concepts: Number Field · Ideal Class Group · Galois Extension · ramification index of a local number-field extension

Overview

The Hilbert class field gives a Galois interpretation of ideal classes. A group originally defined by multiplying ideals becomes the automorphism group of a distinguished extension of the number field. This converts the question whether a prime ideal is principal into a question about its splitting in that extension.

This is a specific consequence of global class field theory. The full theory also treats abelian extensions with ramification, using ray class groups or idele class groups; the Hilbert class field alone does not classify those extensions.

Prerequisites

Know finite Galois extensions, decomposition of prime ideals, ramification indices and the ordinary ideal class group. A Frobenius automorphism acts on a finite residue field by a power map. Idele groups are needed only for the proof outline, which assumes the existence and reciprocity theorems of global class field theory.

Definition and conventions

Fix an algebraic closure of a number field KKK. Its ordinary Hilbert class field HKH_KHK​ is the maximal abelian extension of KKK that is unramified at every finite prime and in which every real place splits completely. Equivalently, form the compositum of all finite abelian extensions with these properties; class field theory proves that the compositum is finite.

The condition at a real place says that its extensions remain real, rather than becoming complex. Authors sometimes use “unramified” only for finite primes. Allowing real places to become complex can produce a larger class field corresponding to the narrow class group. Here the ordinary convention agrees with the existing ideal-class-group entry. Zhang, Proposition 3.76 and its preceding paragraph explicitly makes this distinction.

Intuition

A principal ideal is trivial after passing to the class group. Reciprocity realizes the same triviality as an identity automorphism. The extension packages all ideal classes simultaneously, so prime splitting tests their classes without selecting generators.

“Maximal” is relative to the fixed base KKK and to abelian extensions. Iterating Hilbert class fields changes the base at each stage. A tower can therefore continue beyond the first field, and the theorem does not say that every unramified extension of KKK lies in HKH_KHK​.

Examples and non-examples

Since Z\mathbb ZZ is principal, Cl⁡(Q)=1\operatorname{Cl}(\mathbb Q)=1Cl(Q)=1 and HQ=QH_{\mathbb Q}=\mathbb QHQ​=Q. Likewise, the Euclidean ring Z[i]\mathbb Z[i]Z[i] has class number one, so HQ(i)=Q(i)H_{\mathbb Q(i)}=\mathbb Q(i)HQ(i)​=Q(i). An imaginary quadratic base need not have a nontrivial Hilbert class field.

By contrast, K=Q(−5)K=\mathbb Q(\sqrt{-5})K=Q(−5​) has class group of order two, as calculated in the ideal-class-group article. Hence [HK:K]=2[H_K:K]=2[HK​:K]=2. The ideal p=(2,1+−5)\mathfrak p=(2,1+\sqrt{-5})p=(2,1+−5​) is nonprincipal and has class of order two. Its Frobenius is therefore the nonidentity automorphism, so p\mathfrak pp remains prime in HKH_KHK​ and has residue degree two. This concerns a prime of KKK; the rational prime 222 already ramifies in K/QK/\mathbb QK/Q.

The abelian extension Q(i)/Q\mathbb Q(i)/\mathbb QQ(i)/Q is not a Hilbert class field extension of Q\mathbb QQ: the prime 222 ramifies, and the real place becomes complex.

Important properties

The Hilbert class field theorem gives a canonical isomorphism

Cl⁡(K)⟶Gal⁡(HK/K),[p]⟼Frob⁡p.\operatorname{Cl}(K)\longrightarrow\operatorname{Gal}(H_K/K), \qquad [\mathfrak p]\longmapsto\operatorname{Frob}_{\mathfrak p}.Cl(K)⟶Gal(HK​/K),[p]⟼Frobp​.

We use arithmetic Frobenius, acting on residue fields by x↦xNpx\mapsto x^{N\mathfrak p}x↦xNp. Inverting all Frobenius elements gives the alternative geometric convention. Since the extension is abelian and unramified, the element does not depend on a choice of prime above p\mathfrak pp.

Consequently [HK:K]=hK[H_K:K]=h_K[HK​:K]=hK​, and a nonzero prime ideal splits completely exactly when it is principal. More generally, its residue degree is the order of its class. Every finite abelian extension satisfying the defining local conditions is a subfield of HKH_KHK​.

Proof outline, assuming global class field theory: quotient the idele class group by the images of all finite local unit groups and all archimedean multiplicative groups. The quotient identifies with the ordinary ideal class group. The existence theorem supplies its finite abelian extension; local reciprocity makes finite inertia trivial and real places split. Global reciprocity identifies the quotient map with the Artin map, proving the stated isomorphism and maximality.

Connections and further reading

Characters of the class group give ideal-character L-functions. The abelian factorization theorem expresses ζHK\zeta_{H_K}ζHK​​ as their product, joining the Galois description to analytic ideal counting. These are generally Hecke L-functions over KKK, rather than ordinary Dirichlet L-functions over Q\mathbb QQ. Sutherland, Section 22.6 discusses why the abelian restriction is essential.
