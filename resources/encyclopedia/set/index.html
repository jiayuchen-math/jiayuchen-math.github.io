A set is an extensional object determined by its members, with legitimate constructions controlled by the background axioms.

Reading routes: Sets, proof and mathematical language

Overview

Sets provide a language for collecting mathematical objects and comparing collections. Their defining feature is extensionality: membership, rather than the order of a description or the number of times something is mentioned, determines identity. This makes sets useful for solution spaces, possible outcomes, and domains of functions. A set of solutions records which answers are allowed without recording how an algorithm found them.

Prerequisites

No advanced course is required. Read x∈Ax\in Ax∈A as “xxx belongs to AAA,” and distinguish a mathematical object from a collection containing that object. Logical phrases such as “every” and “there exists” enter naturally when expressing membership conditions.

Definition and conventions

In Zermelo–Fraenkel set theory, set and membership are primitive notions rather than definitions in terms of simpler objects. Extensionality asserts

∀A ∀B  [∀x  (x∈A↔x∈B) →A=B].\forall A\,\forall B\;\bigl[\forall x\;(x\in A\leftrightarrow x\in B)\ \to A=B\bigr].∀A∀B[∀x(x∈A↔x∈B) →A=B].

Write A⊆BA\subseteq BA⊆B when every member of AAA belongs to BBB; equality is allowed. Write A⊊BA\subsetneq BA⊊B when additionally A≠BA\ne BA=B. The empty set ∅\emptyset∅ has no members. The expression {x∈U:P(x)}\{x\in U:P(x)\}{x∈U:P(x)} selects members of an already available set UUU satisfying a specified formula. It does not license forming a set from every imaginable condition without an ambient set.

Intuition

Think of membership as a yes-or-no test. A description can change while its answers remain identical. For instance, “integers strictly between one and four” and “the integers two and three” select the same objects. This explains why set equality is proved by checking membership in both directions. It also explains why a list with repeated entries may describe a perfectly ordinary set.

Examples and non-examples

Let A={2,3}A=\{2,3\}A={2,3} and B={3,5}B=\{3,5\}B={3,5}. Then A∩B={3}A\cap B=\{3\}A∩B={3}, A∪B={2,3,5}A\cup B=\{2,3,5\}A∪B={2,3,5}, and A∖B={2}A\setminus B=\{2\}A∖B={2}. The set {2,2,3}\{2,2,3\}{2,2,3} is still AAA, whereas the sequences (2,2,3)(2,2,3)(2,2,3) and (2,3)(2,3)(2,3) differ.

Also ∅≠{∅}\emptyset\ne\{\emptyset\}∅={∅}: the latter contains one member. A proposed “set of all sets” is a non-example in ZF. If it were a set UUU, separation would produce R={x∈U:x∉x}R=\{x\in U:x\notin x\}R={x∈U:x∈/x}. Substituting RRR gives R∈RR\in RR∈R exactly when R∉RR\notin RR∈/R, a contradiction.

Important properties

To prove A=BA=BA=B, establish both A⊆BA\subseteq BA⊆B and B⊆AB\subseteq AB⊆A. This is more informative than comparing names or presentations. The same method proves identities: x∈A∩Bx\in A\cap Bx∈A∩B means both membership conditions hold, so reversing their order shows A∩B=B∩AA\cap B=B\cap AA∩B=B∩A. The empty set is a subset of every set because no member can violate the required implication.

Connections and further reading

Functions and relations can be encoded using sets of ordered pairs. Power sets collect possible subcollections, while quotient sets collect equivalence classes. Read Logic and Proof, §11.1 and §11.4 for elementary constructions, and Li, “ZFC 公理一览” for their axiomatic setting.
