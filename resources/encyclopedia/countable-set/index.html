A countable set is finite or can be listed by the natural numbers without omission or repetition.

Chinese translation, usage & terminology

Prerequisite concepts: Set · injective function · surjective function · bijective function

Reading routes: Sets, proof and mathematical language

Overview

Countability expresses the possibility of assigning distinct natural-number labels to every member of a set. It includes infinite collections, so it measures something different from whether a counting process eventually stops. The integers and rational numbers are countable, whereas the real numbers are not. This distinction underlies enumeration arguments in logic and the separation between discrete data and the continuum.

Prerequisites

Use functions, injections, surjections and bijections, together with elementary induction. Take N={0,1,2,…}\mathbb N=\{0,1,2,\ldots\}N={0,1,2,…}. A list means a mathematically specified function; no requirement of an effective computer algorithm is built into countability.

Definition and conventions

A set AAA is countably infinite if there is a bijection N→A\mathbb N\to AN→A. It is countable if it is finite or countably infinite. Thus ∅\emptyset∅ is countable. Some texts reserve “countable” for the infinite case; this article follows the inclusive convention of the existing terminology entry.

Equivalently, AAA is countable exactly when it admits an injection into N\mathbb NN. For nonempty AAA, this is also equivalent to a surjection N→A\mathbb N\to AN→A. The nonempty assumption is necessary: there is no function from N\mathbb NN to ∅\emptyset∅. Repetitions in a surjective enumeration can be removed by keeping each element at its first occurrence.

Intuition

An infinite list has no final position, but each particular member must appear at some finite position. Reading the first row of an infinite array completely before starting the second row therefore fails to enumerate the array. A diagonal traversal succeeds because only finitely many pairs precede any specified diagonal.

Countability also concerns the elements themselves rather than how densely they sit in another space. Arbitrarily fine approximation and cardinality are different questions.

Examples and non-examples

To enumerate Z\mathbb ZZ, start with 000, then alternate positive and negative integers:

0,1,−1,2,−2,3,−3,….0,1,-1,2,-2,3,-3,\ldots.0,1,−1,2,−2,3,−3,….

More explicitly, send 000 to 000, 2k−12k-12k−1 to kkk, and 2k2k2k to −k-k−k for k≥1k\ge1k≥1. Every nonzero integer appears once, with its sign determining the parity of its index.

For rational numbers, list pairs (p,q)(p,q)(p,q) with p∈Zp\in\mathbb Zp∈Z and q≥1q\ge1q≥1 in increasing order of ∣p∣+q|p|+q∣p∣+q, and map each pair to p/qp/qp/q. Each stage is finite and each rational number eventually appears. Removing duplicate values gives a bijection with N\mathbb NN. Although Q\mathbb QQ is dense in R\mathbb RR, it remains countable.

Important properties

Subsets and images of countable sets are countable. For a subset, restrict an injection into N\mathbb NN; for an image, use the original enumeration and discard repetitions. Finite Cartesian products of countable sets are countable, using diagonal enumeration of pairs and induction.

In ordinary ZFC mathematics, a countable union of countable sets is countable. The proof idea is to enumerate each nonempty set, then enumerate the pairs consisting of a set index and a position in its list. If the individual enumerations have not been supplied, choosing them is a choice step; that distinction matters when working without the axiom of choice.

Finite strings over a countable alphabet form a countable set: group them by length, use finite products for each length, then take a countable union. This argument does not apply to infinite strings.

Connections and further reading

Finite syntax over a countable stock of symbols explains why many logical constructions can be arranged in stages. Countable sets also prepare the cardinal comparisons in the continuum hypothesis. In dynamics, a discrete forward orbit is countable because it is an image of N\mathbb NN, even when its closure is much larger.

Read Logic and Proof, §§22.2–22.3 for enumeration and diagonalization, and Gowers, facts (B) and (D) for the union and power-set arguments.
