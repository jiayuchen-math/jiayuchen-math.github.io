Foundations & Logic · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Universal quantification asserts that a formula holds for every element of a specified domain, with all other parameters fixed.

Chinese translation, usage & terminology

Prerequisite concepts: first-order sentence

Reading routes: Sets, proof and mathematical language

Overview

The universal quantifier turns a claim about an unspecified object into a claim about every object in a domain. It is written ∀\forall∀, read “for all.” Many mathematical theorems have this shape, even when prose hides the symbol. Stating the domain and the position of other quantifiers is part of stating the theorem correctly.

Prerequisites

Understand predicates, variables, and implication. A structure supplies a domain and meanings for function and relation symbols. Free variables receive values from an assignment; bound variables are controlled by quantifiers. These distinctions prevent an assertion about a chosen example from being mistaken for a general law.

Definition and conventions

For a first-order structure MMM with nonempty domain DDD and an assignment sss,

M,s⊨∀x φ⟺M,s[x↦a]⊨φ for every a∈D.M,s\models\forall x\,\varphi \quad\Longleftrightarrow\quad M,s[x\mapsto a]\models\varphi\text{ for every }a\in D.M,s⊨∀xφ⟺M,s[x↦a]⊨φ for every a∈D.

The assignment s[x↦a]s[x\mapsto a]s[x↦a] changes only the value of xxx. Use parentheses to specify scope. Restricted notation ∀x∈A  P(x)\forall x\in A\;P(x)∀x∈AP(x) abbreviates ∀x  (x∈A→P(x))\forall x\;(x\in A\to P(x))∀x(x∈A→P(x)) in a language where that membership condition is meaningful. An empty restricting set therefore makes this statement true, even though ordinary first-order structures here have nonempty domains.

Intuition

A universal assertion survives every permitted challenge. An opponent chooses the input; the argument must handle it without imposing extra conditions. A proof beginning “let nnn be arbitrary” expresses exactly this obligation. Arbitrary does not mean randomly sampled, nor does it mean selected because it has a convenient special property.

Examples and non-examples

For every integer nnn, the product n(n+1)n(n+1)n(n+1) is even: one of two consecutive integers is even, and multiplication preserves divisibility by two. This is a proof for an arbitrary integer, rather than a check of a finite list. In contrast, ∀n∈Z  (n2>0)\forall n\in\mathbb Z\;(n^2>0)∀n∈Z(n2>0) fails at n=0n=0n=0.

Over the integers, ∀x ∃y  (y=x+2)\forall x\,\exists y\;(y=x+2)∀x∃y(y=x+2) holds: after receiving xxx, choose y=x+2y=x+2y=x+2. The reversed statement ∃y ∀x  (y=x+2)\exists y\,\forall x\;(y=x+2)∃y∀x(y=x+2) fails. For x=0x=0x=0 it requires y=2y=2y=2, while x=1x=1x=1 requires y=3y=3y=3. A single witness cannot meet both requirements.

Important properties

Universal elimination substitutes a suitable term for the quantified variable, with substitution arranged to avoid capture. Universal introduction requires that the variable be absent from the undischarged assumptions on which the conclusion depends. From the temporary assumption x=0x=0x=0, one cannot conclude that every xxx equals zero.

Classically, negating a universal statement gives an existential counterexample: ¬∀x P(x)\neg\forall x\,P(x)¬∀xP(x) is equivalent to ∃x ¬P(x)\exists x\,\neg P(x)∃x¬P(x). This is why one explicit failure disproves a universal claim. Constructive logic treats some of these equivalences more cautiously.
