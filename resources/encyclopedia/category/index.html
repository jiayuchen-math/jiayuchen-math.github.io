Category Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

A category specifies objects, morphisms and associative composition, including an identity at each object.

Chinese translation, usage & terminology

Prerequisite concepts: function between sets · Partial Order · Group

Reading routes: Categorical language toward higher structures

Overview

A category is a mathematical setting in which objects can be connected by composable morphisms. It retains the distinction between a transformation and its source and target. This makes the same language useful for sets and functions, vector spaces and linear maps, ordered sets, and many constructions without underlying elements.

The point is not simply to rename functions as arrows. The allowed arrows determine what structure is visible. All functions between topological spaces and only continuous functions between them produce different mathematical settings, even if their object lists agree.

Prerequisites

Understand functions, composition, and identity maps. Groups and partial orders provide examples in which arrows behave differently from arbitrary functions. Familiarity with classes versus sets helps with size conventions but is not needed for finite examples.

Our composition order applies the rightmost arrow first. A category is small if its objects and morphisms form sets. It is locally small if each collection Hom⁡C(X,Y)\operatorname{Hom}_{\mathcal C}(X,Y)HomC​(X,Y) is a set; its entire collection of objects may still be larger. Set-theoretic universes provide another way to manage size.

An isomorphism is a morphism f:X→Yf:X\to Yf:X→Y admitting a two-sided inverse. Merely having an arrow in each direction does not establish an isomorphism.

Intuition

Objects are locations and morphisms are permitted journeys. Composition records the resulting journey, not necessarily the literal path taken. Associativity lets a string of journeys be combined without parentheses. It does not say that two different routes between the same locations must agree: that additional assertion is the content of a commutative diagram.

Examples and non-examples

In Set\mathbf{Set}Set the objects are sets and morphisms are functions. In Vectk\mathbf{Vect}_kVectk​ they are vector spaces and linear maps. The identity linear map and composite of linear maps give the required operations.

A partially ordered set gives a category with exactly one arrow x→yx\to yx→y when x≤yx\le yx≤y. Reflexivity supplies identities and transitivity supplies composition. For the divisibility order on positive integers, arrows 2→62\to62→6 and 6→306\to306→30 compose to 2→302\to302→30.

A group gives a category with one object: group elements are its endomorphisms and multiplication is composition. More generally any monoid works; invertibility is not a category axiom.

A directed graph alone need not be a category. Three vertices and arrows a→ba\to ba→b, b→cb\to cb→c, but no arrow a→ca\to ca→c, cannot support the required composition. One can instead form the free category of paths in the graph, which adds the missing composites and identities.

Important properties

Identities are unique. If eee and e′e'e′ both act as identities at an object, then e=e∘e′=e′e=e\circ e'=e'e=e∘e′=e′. A two-sided inverse is also unique: if ggg and hhh invert fff, then g=g(fh)=(gf)h=hg=g(fh)=(gf)h=hg=g(fh)=(gf)h=h.

Reversing every arrow produces the opposite category Cop\mathcal C^{\mathrm{op}}Cop. Associativity survives reversal, so statements about arrows into objects have dual statements about arrows out of objects. Products and coproducts are an important example of this duality.
