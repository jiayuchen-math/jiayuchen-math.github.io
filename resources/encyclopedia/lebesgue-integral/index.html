Lebesgue积分

Analysis, Measure & PDE · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

The Lebesgue integral accumulates measurable values by approximation with simple functions.

Chinese translation, usage & terminology

Prerequisite concepts: Lebesgue Measure · measurable real function · simple measurable function

Reading routes: Integration, Fourier methods and weak solutions

Overview

The Lebesgue integral extends integration by measuring where a function takes its values. Its definition works on an abstract measure space, so the same framework handles Euclidean volume and discrete counting. The method is especially useful for limits of functions, where pointwise behavior and total accumulated mass can diverge.

A nonnegative measurable function always has an extended integral, possibly infinity. Calling a real or complex function integrable is a stronger assertion: its absolute value must have finite integral.

Prerequisites

Understand measures, measurable functions, and finite-valued simple functions. A simple function can be written using finitely many indicators of measurable sets. Such functions are the building blocks from which general nonnegative integrands are approximated.

Intuition

Instead of demanding good behavior on every small input interval, group points according to approximate output height. Each height is multiplied by the measure of the region carrying it. Finer simple approximations capture increasingly detailed value information.

Examples and non-examples

On [0,1][0,1][0,1], the indicator of the rationals has Lebesgue integral zero because its supporting set is null. Every interval contains both rational and irrational points, so its Riemann upper sums are one and lower sums zero. This is a concrete enlargement of integration, rather than a different value for a Riemann integrable function.

Important properties

For integrable functions the integral is linear and satisfies ∣∫f∣≤∫∣f∣|\int f|\le\int|f|∣∫f∣≤∫∣f∣. Altering a function on a null set does not change its integral, under the relevant measurability convention.

Monotone convergence permits increasing nonnegative measurable approximations to pass through the integral, even when the answer is infinite. Dominated convergence permits almost-everywhere limits when one integrable function bounds all absolute values. The domination hypothesis prevents a shrinking spike from retaining hidden mass: n1(0,1/n)n\mathbf1_{(0,1/n)}n1(0,1/n)​ tends to zero almost everywhere while all its integrals equal one.
