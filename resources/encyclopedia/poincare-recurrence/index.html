庞加莱回复定理

Dynamical Systems · Graduate · Mathematics Resources editorial compilation (AI-assisted)

In a probability-preserving system, almost every point of each measurable set returns to that set infinitely often.

Chinese translation, usage & terminology

Prerequisite concepts: Probability Space · measure-preserving transformation · almost everywhere · Orbit of a Dynamical System

Reading routes: Orbits, recurrence and ergodic ideas

Overview

Poincaré recurrence says that finite invariant measure prevents almost all starting points from leaving a measurable region permanently. It applies even when the map is not invertible and the trajectories are not chaotic. The theorem supplies infinitely many returns, rather than a numerical return schedule or exact repetition of the starting state.

Prerequisites

Work on a probability space (X,B,μ)(X,\mathcal B,\mu)(X,B,μ) with a measurable self-map TTT. Measure preservation means μ(T−1A)=μ(A)\mu(T^{-1}A)=\mu(A)μ(T−1A)=μ(A) for every A∈BA\in\mathcal BA∈B. Here T−1AT^{-1}AT−1A is a preimage, so this notation requires no inverse function. Understand null sets, countable additivity and iteration.

Definition and conventions

The Poincaré recurrence theorem states that, for each measurable AAA,

μ({x∈A:Tn(x)∈A for only finitely many n≥1})=0.\mu\bigl(\{x\in A:T^n(x)\in A \text{ for only finitely many }n\ge1\}\bigr)=0.μ({x∈A:Tn(x)∈A for only finitely many n≥1})=0.

Equivalently, almost every x∈Ax\in Ax∈A admits positive integers nk→∞n_k\to\inftynk​→∞ with Tnk(x)∈AT^{n_k}(x)\in ATnk​(x)∈A. The exceptional null set may depend on AAA. The assertion is automatic when μ(A)=0\mu(A)=0μ(A)=0, and useful when AAA has positive measure.

The same conclusion holds when 0<μ(X)<∞0<\mu(X)<\infty0<μ(X)<∞, by normalizing μ\muμ. Ergodicity and mixing are additional hypotheses used in other theorems; neither is needed here.

Intuition

Imagine a set of points that never comes back. Its successive preimages are disjoint: belonging to two would imply that a point in the original set eventually returns there. Invariance assigns equal measure to all these disjoint preimages. Finite total measure then forces the original set to have measure zero. This argument works without assuming the forward images are disjoint or have unchanged measure.

Examples and non-examples

Let X=Z/7ZX=\mathbb Z/7\mathbb ZX=Z/7Z carry uniform probability and set T(x)=x+2T(x)=x+2T(x)=x+2. For A={0,1}A=\{0,1\}A={0,1}, the orbit from 000 reads

0,2,4,6,1,3,5,0,….0,2,4,6,1,3,5,0,\ldots.0,2,4,6,1,3,5,0,….

Its first positive return to AAA is at time four, and later visits repeat indefinitely. In this finite probability space each singleton has positive measure, so there can be no nonempty null exceptional set.

The identity map on [0,1][0,1][0,1] with Lebesgue probability returns every point to its original set at every time. Yet it is neither ergodic nor strongly mixing: the invariant half-interval has measure 1/21/21/2. Recurrence is therefore much weaker than either property.

By contrast, T(n)=n+1T(n)=n+1T(n)=n+1 on Z\mathbb ZZ preserves counting measure, but 000 never returns to {0}\{0\}{0}. The space has infinite total measure. Finite volume cannot simply be dropped from the general theorem.

Almost every point is also different from every point. The map T(x)=x/2T(x)=x/2T(x)=x/2 on [0,1][0,1][0,1] preserves the probability measure concentrated at zero. Every positive point tends toward zero and has a neighborhood it eventually leaves forever. All these exceptions together have measure zero for this invariant measure.

Important properties

Proof sketch for the full infinite-return assertion: fix AAA and put

B=A∖⋃n≥1T−nA.B=A\setminus\bigcup_{n\ge1}T^{-n}A.B=A∖n≥1⋃​T−nA.

This is the measurable set of points in AAA with no future return. If a point lay in both T−iBT^{-i}BT−iB and T−jBT^{-j}BT−jB, with i<ji<ji<j, then Ti(x)∈BT^i(x)\in BTi(x)∈B would return to B⊆AB\subseteq AB⊆A after j−ij-ij−i steps, a contradiction. Thus these preimages are pairwise disjoint. Each has measure μ(B)\mu(B)μ(B), and finite total measure forces μ(B)=0\mu(B)=0μ(B)=0.

A point of AAA with only finitely many future visits has a last visit, counting time zero. At that time it enters BBB. All such points therefore lie in ⋃m≥0T−mB\bigcup_{m\ge0}T^{-m}B⋃m≥0​T−mB, a null set by invariance and countable subadditivity. This proves the theorem for noninvertible maps as well.

For a metric space with a countable base of measurable open sets, apply the theorem to each basic open set and combine the countably many exceptional sets. Outside their union, a point returns to every neighborhood of itself infinitely often. This topological conclusion uses the countable-base assumption to control the exceptional sets simultaneously.

Connections and further reading
