函子

Category Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

A functor assigns objects and morphisms between categories while preserving identities and composition.

Chinese translation, usage & terminology

Prerequisite concepts: Category · function between sets

Reading routes: Categorical language toward higher structures

Overview

A functor is a structure-preserving passage between categories. It converts both objects and the maps relating them. This second requirement makes categorical constructions useful: transforming an input map produces an output map, and successive transformations remain compatible with composition. Merely assigning an invariant to each object supplies less information.

Prerequisites

Know a category’s objects, morphisms, composition, and identity morphisms. Concrete examples include sets with functions and vector spaces over a fixed field with linear maps. Be comfortable with the direction of a map: its domain and codomain determine whether another map can be composed with it.

Intuition

A functor translates an entire system of relationships, not just a collection of names. If one calculation can be done in two stages, translating the stages should agree with translating their composite. This requirement permits information to move through a construction without repeatedly rebuilding it from scratch.

The identity equation follows coordinatewise.

Preserving identities is an independent obligation. Regard the natural numbers under addition as a one-object category. Sending every morphism to the zero linear map on a nonzero vector space preserves composition, because zero composed with zero is zero. It fails the identity axiom: the monoid identity 000 must map to the identity linear map, not the zero map.

Important properties

Every functor preserves isomorphisms. If gf=1Xgf=1_Xgf=1X​ and fg=1Yfg=1_Yfg=1Y​, applying FFF makes F(g)F(g)F(g) a two-sided inverse of F(f)F(f)F(f). A functor need not reflect isomorphisms or distinguish different arrows.

Faithfulness means each induced map on hom-sets is injective; fullness means each is surjective. These conditions concern arrows between specified object pairs. Neither is a claim that the functor gives an injective or surjective function on objects.

Connections and further reading

Natural transformations compare functors, while adjunctions pair functors through universal mapping properties. Representable functors use maps to or from an object as probes of its structure. See Riehl, §1.3, Definition 1.3.1 and Li, “函子与自然变换,” definition labelled def:functor.
