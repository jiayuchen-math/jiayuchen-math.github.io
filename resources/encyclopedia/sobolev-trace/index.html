Sobolev函数的迹

Analysis, Measure & PDE · Graduate · Mathematics Resources editorial compilation (AI-assisted)

A Sobolev trace assigns boundary values by continuously extending restriction from smooth functions.

Chinese translation, usage & terminology

Prerequisite concepts: Sobolev Space · Weak Derivative · Lebesgue Lp Space

Overview

A Sobolev trace supplies boundary values for functions whose regularity is measured by integrals rather than pointwise smoothness. It is what makes a Dirichlet condition meaningful for an energy solution of a PDE.

An LpL^pLp equivalence class records values only up to sets of volume zero, while a smooth boundary itself has volume zero. Arbitrarily assigning values on that boundary therefore cannot define a boundary operator on equivalence classes. The trace is instead determined by interior Sobolev regularity and approximation.

Intuition

Derivative control couples nearby interior layers, preventing them from carrying unrelated boundary values at small Sobolev cost. The trace estimate formalizes that coupling. It does not generally assert a pointwise boundary limit at every boundary point. The output is itself an equivalence class on the boundary.

Connections and further reading

Zero trace defines homogeneous Dirichlet data in weak elliptic problems. Nonzero data can be handled by choosing a Sobolev extension and subtracting it before solving a zero-boundary problem. Hunter, §3.9 develops the first-order construction; 程代展、赵寅, §3.9 describes the Hilbert-space trace range.
