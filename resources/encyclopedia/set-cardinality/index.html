集合的基数

Foundations & Logic · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Cardinality measures set size by bijections, with injections providing a comparison of sizes.

Chinese translation, usage & terminology

Prerequisite concepts: bijective function · injective function

Reading routes: Sets, proof and mathematical language

Overview

Cardinality extends counting beyond finite collections. Instead of placing two collections side by side geometrically, it asks whether their elements can be paired without omissions or repetitions. Infinite sets make this viewpoint indispensable: a proper subset can have the same cardinality as the whole set.

Prerequisites

Understand injective, surjective, and bijective functions. A bijection pairs every input with exactly one output and reaches the entire codomain. Take N\mathbb NN to start at zero. This article uses the usual ZFC background when referring to every cardinal as an initial ordinal.

Definition and conventions

Sets AAA and BBB have the same cardinality, written ∣A∣=∣B∣|A|=|B|∣A∣=∣B∣, when a bijection A→BA\to BA→B exists. Write ∣A∣≤∣B∣|A|\leq|B|∣A∣≤∣B∣ when an injection A→BA\to BA→B exists. In ZFC, ∣A∣|A|∣A∣ can be represented by the least ordinal bijective with AAA. The comparison language itself can be used before choosing such representatives.

A set is countable here when it is finite or bijective with N\mathbb NN. Some texts reserve “countable” for the infinite case; “countably infinite” removes this ambiguity. Countability says a listing exists, not that a computable listing has been supplied.

Intuition

Moving elements farther apart changes their spacing but not their number of possible matches. The map n↦3nn\mapsto3nn↦3n pairs N\mathbb NN with its multiples of three. The infinite case therefore breaks the finite intuition that deleting elements must decrease size.

Examples and non-examples

The set A={0,3,6,…}A=\{0,3,6,\ldots\}A={0,3,6,…} has cardinality ℵ0\aleph_0ℵ0​: the displayed map is injective, and every member of AAA is 3n3n3n for a unique nnn. The same formula regarded as a map N→N\mathbb N\to\mathbb NN→N is not surjective, since it misses one. The codomain matters.

The power set P(N)\mathcal P(\mathbb N)P(N) is not countable. Given any proposed listing S0,S1,…S_0,S_1,\ldotsS0​,S1​,…, form D={n:n∉Sn}D=\{n:n\notin S_n\}D={n:n∈/Sn​}. At index kkk, the sets DDD and SkS_kSk​ disagree about membership of kkk, so the listing misses DDD.

Important properties

The Cantor–Bernstein theorem turns injections in both directions into a bijection, with no axiom of choice needed for that theorem. A constructive proof partitions the two sets into chains initiated outside one image and uses one injection on some chains and the inverse of the other on the rest.

Cantor’s argument works for every set AAA: no map A→P(A)A\to\mathcal P(A)A→P(A) is surjective. The singleton map provides an injection the other way, so ∣A∣<∣P(A)∣|A|<|\mathcal P(A)|∣A∣<∣P(A)∣.

Connections and further reading

Cardinal size differs from order type: N\mathbb NN and Z\mathbb ZZ have equal size but different usual order structures. The continuum hypothesis concerns a possible cardinal between the natural numbers and their power set. Read Logic and Proof, §22.1–§22.5 and Li, “基数”.
