Prerequisite concepts: Integer Divisibility

Overview

The greatest common divisor measures the common divisibility of two integers. It also answers an apparently different question: which integers can be made by adding integer multiples of the two inputs? This second interpretation makes the gcd useful for linear Diophantine equations, modular inverses, and calculations with ideals.

Prerequisites

For integers d,nd,nd,n, write d∣nd\mid nd∣n if n=dkn=dkn=dk for some integer kkk. Understand division with remainder: for b>0b>0b>0, every integer aaa has a unique expression a=qb+ra=qb+ra=qb+r with 0≤r<b0\le r<b0≤r<b. Negative inputs can be replaced by their absolute values when computing a gcd.

Definition and conventions

If a,ba,ba,b are not both zero, gcd⁡(a,b)\gcd(a,b)gcd(a,b) is the unique positive integer ddd dividing both such that every common divisor divides ddd. Equivalently, it is their largest positive common divisor. We use the extension gcd⁡(0,0)=0\gcd(0,0)=0gcd(0,0)=0 and gcd⁡(a,0)=∣a∣\gcd(a,0)=|a|gcd(a,0)=∣a∣; this convention keeps the ideal characterization valid even for zero inputs. Two integers are coprime when their gcd is 111, without any requirement that either integer itself be prime.

Intuition

Divisibility is a better guide than numerical size. The gcd gathers exactly the prime powers shared by the inputs, using the smaller exponent at each prime. Yet computing it need not require factoring either input. Repeated remainder operations preserve the common divisors while shrinking the numbers under consideration.

Important properties

For inputs not both zero, there exist integers u,vu,vu,v with au+bv=dau+bv=dau+bv=d. To see the mechanism, choose the smallest positive integer linear combination. Dividing either input by that combination leaves a remainder that is again a linear combination. Minimality forces each remainder to vanish. Every common divisor divides all such combinations, completing the argument.

Consequently aZ+bZ=dZa\mathbb Z+b\mathbb Z=d\mathbb ZaZ+bZ=dZ, and ax+by=cax+by=cax+by=c is solvable precisely when d∣cd\mid cd∣c. If gcd⁡(a,m)=1\gcd(a,m)=1gcd(a,m)=1, reducing au+mv=1au+mv=1au+mv=1 modulo mmm produces a multiplicative inverse of aaa. The coprimality hypothesis cannot be omitted.

Connections and further reading

The Euclidean algorithm supplies the gcd and, by back substitution, its linear-combination coefficients. The same viewpoint extends to principal ideal domains, where a gcd is determined up to multiplication by a unit. See Judson, Section 2.2 and Subsection 2.2.1 for the underlying arithmetic statements.
