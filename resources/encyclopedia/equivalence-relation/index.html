An equivalence relation partitions a set into classes of mutually equivalent elements.

Chinese translation, usage & terminology

Prerequisite concepts: Set · Cartesian product

Reading routes: Sets, proof and mathematical language

Overview

An equivalence relation specifies when two elements should count as interchangeable for a particular purpose. It replaces literal equality with a precisely controlled comparison. The resulting classes let mathematics collect many representatives into one object, as in residue classes, fractions, or objects classified up to a specified relation.

Prerequisites

A binary relation on a set XXX is a subset of X×XX\times XX×X. Write x∼yx\sim yx∼y when (x,y)(x,y)(x,y) belongs to this subset. Know subsets and functions, especially the requirement that a function assign one unambiguous value to every input.

Intuition

A class records a shared feature while forgetting which representative supplied it. For congruence, the feature is a remainder. For reduced fractions, different pairs of integers may name the same rational number. The equivalence conditions ensure that sharing the feature behaves consistently.

Important properties

Two equivalence classes are either equal or disjoint. If zzz belongs to both [x][x][x] and [y][y][y], symmetry and transitivity give x∼yx\sim yx∼y, and then every element equivalent to one is equivalent to the other. Connections and further reading

Quotient constructions appear in algebra, topology, and model building. A preorder can also be converted to a partial order by identifying mutually comparable elements in both directions. See Logic and Proof, §13.3 and Li’s “ZFC 公理一览,” equivalence-relation paragraph.
